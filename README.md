## 🚀 Open-source projects

| Project | What it does |
|---|---|
| [**odoo-rest-api-toolkit**](https://github.com/Pirainuthal/odoo-rest-api-toolkit) | Publish any Odoo model as a secure JSON REST API from the UI: API-key auth, field whitelists, OpenAPI spec, request logs. Odoo 19, 17 HTTP tests. |
| [**odoo-mcp-server**](https://github.com/Pirainuthal/odoo-mcp-server) | Model Context Protocol server so AI assistants (Claude, etc.) can query and update Odoo safely: read-only by default, model allowlists, Odoo access rights. |
| [**odoo-whatsapp-cloud**](https://github.com/Pirainuthal/odoo-whatsapp-cloud) | WhatsApp Cloud API for Odoo 19 Community: send quotations and invoices with PDF, sync templates, receive replies in the chatter, signed webhooks. |
